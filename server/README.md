# WebSocket server

Run `npm install && npm start` inside `server/` on a persistent Node.js host (not Vercel Functions). Set `PORT` as needed and expose the service over HTTPS/WSS behind a reverse proxy. Set `NEXT_PUBLIC_GAME_WS_URL=wss://your-websocket-host` in the Vercel project and redeploy.

The server currently keeps rooms in memory; restarting it removes active rooms. Room codes are six digits. The first player is the flamingo, the second is the robot. Only the active player can roll or move; rolls are generated by the server. No authentication is required.
